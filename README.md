# Dottorconti GitHub Pages

Personal portfolio and project showcase built with Hugo and hosted on GitHub Pages.

## Features

- 🎨 Minimal, responsive design
- 📱 Mobile-friendly
- 🚀 Fast and lightweight
- 📊 Umami Analytics integrated
- 💰 PayPal donation support

## Local Development

```bash
# Clone repository
git clone https://github.com/dottorconti/dottorconti.github.io.git
cd dottorconti.github.io

# Run Hugo server
hugo server -D

# Build for production
hugo --minify
```

## Projects

This site showcases my open source hardware projects:

- **Zaccaria CPU Remake** - Modern CPU board for Zaccaria pinball machines
- **EPROM Adapter** - Replace old EPROMs with modern 2764/27512
- And more...

Visit [dottorconti.net](https://www.dottorconti.net) for detailed technical documentation.
