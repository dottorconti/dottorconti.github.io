❓ Troubleshooting

Browser doesn't recognize USB device?

This tool requires a modern browser with Web Serial API support:

  • ✅ Chrome/Chromium 89+
  • ✅ Edge 89+
  • ❌ Firefox (not supported yet)
  • ❌ Safari (not supported yet)
No COM port appears?
  • Try a different USB cable (data cable, not charge-only)
  • Install USB driver: Silicon Labs CH340/CH341
  • Reboot the ESP32 (hold BOOT button, press RESET)
Flash failed / Checksum error?
  • Try again (sometimes just timing)
  • Use slower USB hub/port
  • Erase flash first: hold BOOT, press RESET 3 times
Which board version do I have?

Check the sticker on your audio board. Common models:

  • 1B1125 - Shooting the Rapids, Hot Wheels (Z1G)
  • 1B1146 - Space Shuttle, Locomotion (Z1G Audio)
  • 1B11136/1B1170/1B11178/1B11183 - Later machines (Z2G)
